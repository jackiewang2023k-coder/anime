# Heart Function Animation

一个使用 HTML、CSS 和 Canvas API 制作的心形函数绘制动画。

## 心形参数方程

```text
x = 16sin³(t)
y = 13cos(t) - 5cos(2t) - 2cos(3t) - cos(4t)
```

## 本地运行

直接双击 `index.html`，或使用 VS Code 的 Live Server。

## 部署到 GitHub Pages

1. 在 GitHub 新建公开仓库，例如 `heart-function-animation`。
2. 上传本项目全部文件并提交。
3. 打开仓库 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/ (root)`，点击 `Save`。
6. 稍等片刻后，访问：

```text
https://你的GitHub用户名.github.io/heart-function-animation/
```
